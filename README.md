
# Task 2: Phishing Email Analysis

## Objective
To study a suspicious email and identify common phishing indicators.

## Key Concepts
- **Phishing:** Fake emails designed to trick people into sharing information or clicking unsafe links.
- **Email Spoofing:** Using a misleading sender name or email address to appear trustworthy.
- **Header Analysis:** Checking email routing and authentication details such as SPF, DKIM and DMARC.
- **Social Engineering:** Using urgency, fear or curiosity to influence a person into taking action.
- **Threat Detection:** Identifying suspicious signs and deciding how to respond safely.

## Sample Used
A fictional Microsoft account security alert created for training.

## Findings
- The sender address contains `micr0soft` (zero instead of the letter `o`).
- The message creates urgency by warning about unusual sign-in activity.
- The displayed link looks legitimate, but the example hover destination uses a different domain.
- No attachment is included.
- Original email headers were not available, so SPF, DKIM and DMARC could not be tested.

## Conclusion
The sample demonstrates phishing, possible sender impersonation and social-engineering techniques. Do not open suspicious links or share account details. Check account activity by visiting Microsoft's official website directly.
